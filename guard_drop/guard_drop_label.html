Conventions

Clip loops the punch window at 0.25x.
1 / 2 / 3 = good / dropped / always too low — saves & advances.
Space = pause/play · ←/→ = step one frame.
U = clear this punch's saved label.
S then 1/2/3 = skip (occluded / unclear / no punch in clip).
Esc = cancel the skip menu.
X = cycle speed 0.25 / 0.5 / 1x.

Judge the resting hand only — the hand that is not throwing. The red badge (top-right of the video) says which one to watch; it flips with stance, so don't go by side. Dropped = it was up and fell during this punch. Always too low = it was never up in the first place. If it never rises above the shoulder at any point in the loop, that's always too low, not dropped.
Shortcuts: 1 = good  |  2 = dropped  |  3 = always too low  |  Space = play/pause  |  ←/→ = ±1 frame  |  U = clear label  |  S = skip  |  Esc = cancel skip  |  N = Next  |  P = Previous  |  F = First  |  G = Next unlabeled  |  X = speed
